# Checkout Psiloshop PixGo

Workspace importado do projeto PixGo para WooCommerce.

## Estrutura

- `plugin/pixgo-payments-wc/`: versao ativa do plugin, importada como base principal.
- `packages/`: ZIP instalavel para upload no WordPress.
- `previews/`: previews HTML usados para validar visual da tela de obrigado.
- `archive/iterations/`: iteracoes antigas preservadas para consulta.
- `docs/`: base de conhecimento e inventario do que foi importado.

## Versao ativa

Plugin: PixGo Payments WC  
Versao: 1.1.7  
Arquivo instalavel: `packages/pixgo-payments-wc-1.1.7.zip`

## Instalacao rapida

1. No WordPress, abra `Plugins > Adicionar novo > Enviar plugin`.
2. Envie `packages/pixgo-payments-wc-1.1.7.zip`.
3. Ative `PixGo Payments WC`.
4. Abra `PSILOSHOP > PixGo Payments WC` para conferir o status.
5. Configure as chaves em `WooCommerce > Configuracoes > Pagamentos > PixGo PIX`.
6. Ative o gateway somente quando as credenciais estiverem prontas.
